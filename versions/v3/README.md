# Version 3

## How this version differs from the others

Version 3 develops the longer, story-led presentation and makes its “get inspired” prompt an invitation to continue into the page. It includes a cinematic product introduction, a closer-look section, brand storytelling, and a collection carousel. The carousel still uses generic card labels, so the experience feels more developed than v2 but less finished in its collection copy than v4 or the root page.

- **Compared with the root page:** v3 has the more exploratory presentation, with more navigation and settings exposed; the root page keeps the product-themed collection descriptions while omitting v4's opening loading screen.
- **Compared with v1:** v3 adds a guided journey and substantial product and brand context to v1's compact watch-focused hero.
- **Compared with v2:** v3 improves the journey from the hero into the rest of the page; v2's “get inspired” prompt does not yet guide visitors onward.
- **Compared with v4:** v3 leaves the loading screen out and uses generic carousel labels. v4 adds the loading introduction and gives the collection cards product-specific titles and descriptions.

## Experience

Choose v3 to see the campaign take shape as a guided sequence, from the watch introduction to the story and rotating collection showcase, before the final card copy and opening presentation are refined.
