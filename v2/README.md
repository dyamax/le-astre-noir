# Version 2

## How this version differs from the others

Version 2 marks the move from a single product hero to a longer, exploratory brand experience. It introduces several destinations within one page—including a product introduction, closer-look area, brand story, and collection carousel—but still feels like a work in progress: the cards have generic labels, and the “get inspired” prompt does not yet lead visitors into the story.

- **Compared with the root page:** v2 has the broader page structure, but its collection cards are generic rather than filled with the root page's product-themed descriptions.
- **Compared with v1:** v2 trades v1's compact, watch-first presentation for a scroll-through experience with more product and brand context.
- **Compared with v3:** v2 is an earlier exploration of the extended layout. v3 makes the “get inspired” prompt guide visitors into the page and develops the flow further.
- **Compared with v4:** v2 has neither v4's opening loading screen nor its fully written collection cards; it presents the extended experience in a more unfinished form.

## Experience

This version is the bridge between the original single-screen concept and the more developed story-led presentations. It keeps the dark watch campaign at its center while beginning to add depth and discovery.
